# Joe Holbrook Memorial Math Competition

Astro website for JHMMC, based on [the original site](https://github.com/bcamathteam/Holbrook-Site). Maintained by Colin Ding ([coldin28@bergen.org](mailto:coldin28@bergen.org)).

Requires Node.js 22 or newer.

```sh
npm ci
npm run dev
npm run verify
```

Pages are in `src/pages/`, shared components in `src/components/`, and maintainer details in `src/data/site.ts`. Images and downloads live in `public/`. Production output is `dist/`.

Third-party attribution is in [THIRD_PARTY.md](THIRD_PARTY.md); license texts are in `licenses/`.
